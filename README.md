# SecurityPlus AI Lab

A responsive, single-page website for SecurityPlus AI Lab at the University at Albany.

## Website sections

- About the lab and its mission
- Research areas: assistive technology, cybersecurity and digital literacy, ethical AI, and emerging technology
- Research priorities and a lifespan approach
- Lab members
- Collaboration and student opportunities
- Contact information

## Run locally

Open `index.html` in a web browser. The page uses plain HTML, CSS, and JavaScript; no build step is required.

## Publish with GitHub Pages

1. In this repository, open **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. The workflow in `.github/workflows/pages.yml` will publish the site after a push to `main`. You can also run it manually from the **Actions** tab.
